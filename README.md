# 📊 React Admin Dashboard (Vite + Tailwind)

A sleek, responsive admin dashboard built with **React** and **Vite**, featuring a real-time UI, interactive charts, dark/light mode, and productivity tools to manage orders, employees, and more.

---

## 🚀 Features

### 📌 Core Dashboard
- 🏠 **Home Page Overview**:
  - Total Revenue
  - Active Employees
  - Orders Count
  - Summary Cards with icons and trends

### 📁 Management Pages
- 📦 **Orders** – Create, view, update, and manage order details
- 👥 **Customers** – Add and view customer records
- 👨‍💼 **Employees** – Manage staff and their roles

### 📅 Productivity Tools
- 📆 **Calendar** – Add events by selecting a date
- 🧩 **Kanban Board** – Drag-and-drop task management

### 📊 Data Visualization (via Chart.js)
- 📈 Line Chart
- 📊 Bar Chart
- 🥧 Pie Chart
- 🧮 Scatter Chart

### 🌙 Dark / Light Mode
- Toggle between elegant dark and light themes for better accessibility and user preference

---

## 🛠️ Tech Stack

- ⚡ **Vite** – Blazing fast build tool
- ⚛️ **React** – UI components
- 🎨 **Tailwind CSS** – Utility-first styling
- 🧭 **React Router** – Client-side routing
- 📊 **Chart.js** – Beautiful, responsive charts
- 🌘 **Dark/Light Mode** – Theme toggle built with Tailwind and React Context
- 📦 **LocalStorage** – For theme and persistent data handling
